# GPT_YT_Crawler

## 프로그램 소개

사용자가 보관할 권한이 있는 YouTube 영상을 Linux 서버에 다운로드하고 Google Drive에 저장하는 개인용 프로그램입니다. 설정에서 켜면 지정한 YouTube 채널에 일부 공개로 업로드합니다. YouTube 업로드는 기본으로 꺼져 있습니다.

다운로드 → Google Drive 저장·검증 → 선택적 YouTube 업로드·검증 → 서버의 영상 임시 파일 삭제 순서로 처리합니다. 실패한 작업은 파일을 보존하며, 영상별 처리 결과와 오류를 일일 기록으로 남깁니다.

Drive 연결 후 설정에서 자동 수신을 켜면, 실행 시작 때 `유튜브 동영상/관리용 파일/youtube-cookies.txt`와 `youtube-token.json`의 변경 여부를 확인하고 바뀐 파일만 서버에 적용합니다. 토큰은 갱신과 지정 채널 조회가 성공해야 교체하며, 이 과정에서 영상 업로드는 켜지지 않습니다. `yt-archive sync-youtube-token`은 영상 수집 없이 토큰만 가져옵니다.

비공개 Google 스프레드시트를 연결하면 `채널 목록`의 체크박스로 채널을 관리하고, `자동 실행` 탭에서 매일 지정 시각 또는 일정 간격 실행을 설정할 수 있습니다. Oracle의 설정 확인 타이머가 약 30분마다 시트를 읽습니다. 실행 중에 자동 실행을 끄면 이번 실행에 포함된 영상들을 끝까지 처리하고, 종료 후 다음 시트 확인에서 꺼짐을 반영해 이후 실행을 멈춥니다. 일정 간격은 켠 뒤 첫 확인 때 시작하고, 매일 지정 시각은 한국시간으로 다가오는 시각부터 예약합니다. 실제 실행은 확인 시점에 따라 늦어질 수 있으며, 30분보다 짧은 반복 간격도 확인 주기의 영향을 받습니다. 작업이 길어지면 동시에 겹쳐 실행하지 않습니다.

시트 연결 시 다운로드 체크를 끈 채널과 목록에서 제거한 채널의 대기 작업은 보존한 채 멈춥니다. YouTube 업로드는 채널별 체크와 기존 전역 업로드 설정을 함께 적용하며, 기본값은 꺼짐입니다.

쿠키·토큰 확인이나 시트 읽기 등 시작 단계의 오류도 실행 실패와 오류 보고서로 기록합니다. Drive 로그 저장을 켰고 연결이 가능하면 `관리용 파일/로그`에 보고서를 올립니다. Drive 연결에 실패해도 서버의 DB와 보고서는 보존합니다. 설정 파일·DB 오류는 별도로 `data/errors.jsonl`에 한국시간과 오류 요약을 누적하며, 파일 저장도 불가능하면 서비스 로그에 남깁니다. 쿠키·토큰의 원문은 오류 기록에 포함하지 않습니다.

## 개인정보처리방침

- **사용 정보:** 영상·썸네일, 제목·설명·채널·게시 시각·원본 링크 등 보관과 처리 확인에 필요한 정보를 사용합니다. YouTube 업로드를 켜면 OAuth 업로드 권한과 채널·영상 상태 조회 권한을 사용합니다.
- **저장·전송:** 인증 토큰·다운로드 쿠키·처리 이력은 사용자가 관리하는 기기에 보관합니다. 사용자가 설정한 Google Drive와, 업로드를 활성화한 경우 YouTube에 영상 및 관련 정보를 전송합니다. 인증 파일 자동 수신 기능은 사용자가 Drive에 올린 쿠키·토큰을 읽어 서버에 적용합니다.
- **이용 목적:** 데이터는 요청한 영상 보관·업로드·상태 확인에만 사용하며, 판매·광고·AI 모델 학습에 사용하지 않습니다. Google 사용자 데이터의 이용은 Google API 서비스 사용자 데이터 정책과 Limited Use 요구사항을 따릅니다.
- **인증 정보 보호:** 실제 쿠키·토큰·개인 설정·운영 기록은 저장소에 포함하지 않습니다. 인증 정보의 원문은 보고서에 기록하지 않습니다.
- **삭제·권한 철회:** 사용자는 보관 파일·처리 기록·인증 파일을 삭제하고 Google 계정의 연결된 앱 설정에서 권한을 철회할 수 있습니다. Drive와 YouTube에 저장한 사본은 각 서비스에서 별도로 삭제할 수 있습니다.
